- **`/cso` now starts inside a Multica managed worktree, and helper faults are named (CHE-9982).** The launcher rejected every managed worktree with `UNSAFE_PATH` because Multica writes `[include] path = multica-identity.config` into the worktree's `config.worktree`. It now accepts only that shape: a plain relative `[include] path` that resolves to a regular file directly inside the Git directory holding the config, with no nested include. The file is bound and re-checked like the config itself. `includeIf`, subsections, absolute or `..` paths, symlinks and working-tree targets are still rejected. A filesystem fault (for example an unwritable `$HOME`) used to be reported as `INVALID_SCHEMA` "The helper rejected an unexpected or unsafe input"; it is now `PERSISTENCE_FAILED` with the errno and, for the state directory, a `GSTACK_HOME` hint.
