- **`/cso` now starts inside a Codex `workspace-write` sandbox (CHE-10265).** There `~/.gstack` is read-only, so the helper failed with `PERSISTENCE_FAILED (EROFS)`. When the default state root cannot be written (EROFS, EACCES or EPERM) and no `GSTACK_STATE_ROOT`, `GSTACK_HOME`, `GSTACK_STATE_DIR` or `CLAUDE_PLUGIN_DATA` is set, the helper retries once under `/tmp/gstack-cso-<uid>` (sticky `/tmp`, per-uid, mode 0700, owned by the current user). Every ancestor and owner check still runs there: a group- or world-writable ancestor, or a directory pre-created by another user, is still rejected with `UNSAFE_PATH`, and an unsafe default root is never retried. An explicit state-root variable is never replaced. Runs made in the sandbox live in the `/tmp` root and are not visible outside it. Not offered on Windows.
